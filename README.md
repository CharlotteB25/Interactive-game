# Template XR

This project is an interactive 3D experience built with **React Three Fiber**, **Three.js**, and **Rapier physics**.  
It showcases a custom 3D environment with models, lighting, interactions, and music.

## Getting Started

If you want to run this project locally after downloading/cloning it from GitHub:

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/template-xr.git
   cd template-xr
   ```

2. **Install dependencies**  
   Make sure you have [Node.js](https://nodejs.org/) installed (recommend LTS version).  
   Then install all required node modules:

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. **Open in browser**  
   Once the server is running, open the local address (usually [http://localhost:5173](http://localhost:5173)) to see the project.

## Project Features

- Fully interactive 3D environment with movement and physics.
- Custom lighting setup (directional, ambient, spotlights).
- Example of state management with `zustand`.
- Includes collision, interaction, and prop components.
- Optimized for smooth navigation and performance.
